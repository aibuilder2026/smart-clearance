The client's first stock export

SC-84 · the console and Munchly's workspace · three options for where staff set up a client's first stock export, so its workspace's Setup opens mapped. Every company, person and figure is fictional.

The maintainer (8 Oct), on the workspace's first screen:

  • “I want this export to be already done by default first time, as from console when the client is being configured this first time export will be configured already, and then later daily syncs can be done or uploaded from UI as needed.”
  • Asked what is done in the console: the export mapped (the client's operator still confirms the guardrails). Asked what a journey reset does to it: keep it.

Now

New client has no step for the data; a client's Integrations tab only asks the distributors for the first export; the workspace opens on “Connect your stock data to start”, and Setup maps the export itself.

What all three share

One card

  • Drop or choose the CSV; it uploads, the Data agent maps its eight fields, and the card shows the mapping with what the file brought (batches, distributors) and who uploaded it.
  • Replace keeps the same card.

Then, as now

  • The Data agent loads each day's export at 08:30 (and the console fires it at once, SC-79).
  • The client's operator can upload an export from Setup at any time.
  • A journey reset keeps the export and its mapping.

The workspace

  • Setup opens mapped, as designed (SC-73).
  • The Command Center's first card says what is left: Confirm Setup to start watching, with the export's batches and distributors, and Review and confirm.

Option A · A step in New client

Recommended

New client gains a Stock data step after Supply chain: staff drop the client's first export, watch the Data agent map its eight fields, and Review lists it. A client already set up keeps the same card at the top of its Integrations tab, to replace the export.

Trade-offs
  • It happens where the client is configured, as asked: the workspace is ready the day it is handed over.
  • The step can wait (“No file to hand? Continue”): the client's Setup still asks for it then.
  • One more step in an eight-step flow.
What the build touches
The console's New client flow and Integrations tab (design3, then frontend/console); a console route for a client's first export in backend-api (store it, publish it to the Data agent, keep its mapping); the reset keeping the mapping; the workspace's first card.

Option B · On the Supply chain tab

The first export sits at the top of the client's Supply chain tab, above the distributors, SKUs and batches it brings. New client ends there: Review says the export comes next, on Supply chain, and the new client opens on that tab.

Trade-offs
  • Cause and effect on one page: the file, then what it brought.
  • Set up just after the client is created, not inside the flow.
  • The tab is long once the client is live; the card moves down the page's purpose.
What the build touches
As A, with the card on the Supply chain tab instead of a New client step.
Open option BA client live

Option C · As a connector

Distributor stock exports is the first row of the client's Integrations, as a connector. It opens a sheet with the first export, its mapping, and what follows: the Data agent's daily load at 08:30, uploads from the workspace's Setup, and the distributors' upload link.

Trade-offs
  • Fits how the console treats every other source of data, with the daily sync in the same place.
  • One click further from the client's page, and nothing in New client says it is due.
  • The sheet is the only place that shows the mapping.
