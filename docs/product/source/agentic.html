3How the agentic infrastructure solves it

Ten agents on Google Cloud do the deciding and the running around, and the money is never a model's guess.

Each hard part of the problem is a stop on a batch's journey, and each stop is one agent's job. The agents are stateless pipelines on Google's Agent Development Kit, woken by an event, thinking with Gemini on Agent Platform. backend-api, the system of record, works out every figure, keeps the journey's state and holds every yes.

1 · EventSomething happens

A morning tick from Cloud Scheduler, a photo sent, a yes, a bid. backend-api records it with its outbox.

2 · AgentPub/Sub wakes one

The event is pushed to the agents on Cloud Run, which run its ADK pipeline once and keep nothing.

3 · FactsIt reads, never writes

The case from backend-api, sell-through from BigQuery, the photo from Cloud Storage.

4 · WordsGemini writes, checked

Structured output, every figure held to the facts, three tries, else a template stands in.

5 · Reportbackend-api decides

It moves the journey on, writes the audit line and tells every screen over the live stream and a push.

Why it can be trusted with money

Code does the arithmetic

Every figure comes from the money rules in backend-api. Gemini writes words, and a note that quotes a wrong number is dropped.

People keep the yeses

Nothing moves before the plan's approval or the distributor's permission; a destruction waits for a second yes on its evidence.

Bounded and safe to retry

Thirty seconds a call, three tries, a budget of calls a run, then a template. A redelivered event changes nothing twice.

Every step on the record

An append-only audit line in the actor's name, and one trace from the tap to Gemini in Cloud Trace.
